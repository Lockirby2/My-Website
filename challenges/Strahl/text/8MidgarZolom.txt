We can't get any Enemy Skill Materia due to the No Scavenging rule, so there's no need to aim for learning Beta here.  Therefore, this fight is optional in this run.  This is done with Aerith since it looks more amusing this way.

Since we don't need Beta, we'll just use the Poison strat.  Enemies will not enter their later phases as long as we don't attack them directly, so as long as we let Poison do all the work, the Zolom will stay in its first phase for the entire fight.  And since the Zolom only uses its regular attack in the first phase, we're generally safe as long as we heal every turn.

That said, we still need to get Poison up, which can be a bit annoying.  We either need the first turn or a miss, neither of which is too likely, and the Poison status doesn't stick every time either.  I got pretty lucky with a miss occurring one one of my first attempts though.  We also need the snake not to crit us, and with how many times it attacks us, we're lucky that didn't happen.
