<a href="https://www.ff6hacking.com/wiki/doku.php?id=ff3:ff3us:util:ff3usme">FF3usME</a> - This is a valuable tool for viewing or modifying game data.  It's easy to use, and it's capable of editing enemy scripts, enemy attibutes, spells, characters, etc.  If you want to do a challenge that's not possible in the vanilla game, FF3usME is your friend.  If you want to shortcut a grind (e.g., by reducing shop prices), this tool can do that too.  Also, if you don't trust the wiki, this tool allows you to view the game data itself, making it infallible as a source of information.

<a href="http://software.gendou.com/details.php?id=6">Save Editor</a> - If you want to directly edit your inventory to add something you could have easily acquired, but forgot, this save editor has your back.  Make sure to edit the .srm save data instead of a save state file.

<a href="https://www.ff6hacking.com/wiki/doku.php?id=ff3:ff3us:tutorial:events">Event hacking tutorial</a> - For more advanced edits (e.g., removing a character from your party before a battle for a solo challenge), you'll need to learn how to edit the game's events.  It isn't a trivial undertaking to learn how to do this, but it's also not <i>that</i> hard.  If you want don't want to learn how to do this just to make a simple change, I'd also be willing to guide you or do it for you if you ask... so long as the thing you're asking for is genuinely a simple change.

<a href="http://www.rpglegion.com/ff6/hack/evade.htm">M. Evade fix</a> - This bug makes the game easier and arguably less fun, so you may want to patch it.
