A little meta, isn't it?  But this website is a pretty substantial project in itself, and I need to back it up on GitHub anyways in case Neocities goes down.  When making this website, I decided I wanted to build it from the ground up rather than using pre-existing frameworks or assets.  I want it to be something that is really mine (for better or for worse) rather than a pile of text that I plugged into something that somebody else built.  It's not exactly artistic, but it's clean and functional.  Given that I come from an enterprise software background, this is hardly a surprise.  As somebody who leans more towards backend development, this was a good learning experience.  I learned a lot about how much better CSS has gotten in the last decade or so, how to make the site responsive, and especially how to make it accessible.  And now I have a little corner of the internet that's uniquely mine!
